## Алгоритм запуска приложения

### Шаг 1. Клонирование репозитория
`git clone <URL>`
### Шаг 2. Собираем образы и запускаем контейнеры
`docker compose up --build`

## Алгоритм запуска тестов

### Шаг 1. Создание и активация виртуального окружения
`python -m venv .venv`
`source .venv/bin/activate`
### Шаг 2. Установка зависимостей
Убедитесь, что в корне проекта есть файл requirements-dev.txt, затем выполните:
`pip install -r requirements-dev.txt`

### Шаг 3. Запуск тестов
`pytest -v -s tests/`
